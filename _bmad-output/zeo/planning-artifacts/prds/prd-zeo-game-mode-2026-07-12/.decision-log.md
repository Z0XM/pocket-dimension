# zeo Game Mode PRD — Decision Log

## 2026-07-12 — Planning session (Party Mode + user confirmation)

| # | Decision | Rationale |
|---|----------|-----------|
| D-GM-1 | Server maintains authoritative game state | Integrity for votes, phases, scoring; clients propose via HTTP POST |
| D-GM-2 | Real-time sync: **SSE + HTTP POST** | Low-latency state push without WebSocket adapter complexity; mutations stay RESTful |
| D-GM-3 | Accept/Reject: proposing team, any member; **first server write wins** | User requirement; race handled via DB transaction (`SELECT FOR UPDATE`) |
| D-GM-4 | Suggestion tile visibility: **client-side hide** | Play-only; not security-sensitive; simpler than server-filtered payloads |
| D-GM-5 | Force next round: **no score** for that round | User confirmed |
| D-GM-6 | Restart round: wipe suggestions/votes only; **no score rollback** | User confirmed |
| D-GM-7 | **Disable guest mode in Zeo entirely** | User confirmed; simplifies game auth and identity model |
| D-GM-8 | Mime rotates **within guessing team** each round | User confirmed |
| D-GM-9 | Shuffle is a **button** (not toggle); press to re-shuffle | User confirmed |
| D-GM-10 | Team switch: **between rounds only** | User confirmed earlier |
| D-GM-11 | Min 2 members per team; uneven teams allowed | User confirmed |
| D-GM-12 | No timers in MVP | Timers deferred to later phase |
| D-GM-13 | Game chat ephemeral; Charades uses suggestion tile | User confirmed |
| D-GM-14 | Charades: no centered game tile | User confirmed |
| D-GM-15 | Room scoreboard persists individual scores across games | User confirmed |
| D-GM-16 | Host decides when to end game (no fixed win condition) | User confirmed |
| D-GM-17 | Shuffle available in lobby + between rounds (not mid-round) | Default accepted; not explicitly challenged |
| D-GM-18 | Logged-in users only for game participation | Follows D-GM-7 |
