## Project Overview

Personal finance ledger for importing Indian bank statements, organizing transactions (categories, tags, groups, refunds), and reviewing spend via dashboards. Auth-backed; PostgreSQL schema `chhanchhan`.

## Quick Reference

- **Tech Stack:** Bun, SvelteKit 2, Svelte 5, Drizzle, Better Auth, Tailwind 4
- **Entry Point:** `apps/chhan-chhan/src/routes/`
- **Architecture Pattern:** Route loaders + form actions + `/api/accounts/...` endpoints
- **Database:** PostgreSQL 18+, schema `chhanchhan`
- **Deployment:** Dockerfile / Railpack from repo root — see `apps/chhan-chhan/DEPLOY.md` (port **3005**)

## Getting Started

### Prerequisites

PostgreSQL 18+, Bun, shared packages built, auth-service running.

### Setup

```bash
# from repo root
bun install && bun run build
cp apps/chhan-chhan/.env.example apps/chhan-chhan/.env
# set DATABASE_URL, BETTER_AUTH_SECRET, PUBLIC_BASE_AUTH_URL=http://localhost:5001
bun run db:migrate
```

### Run Locally

```bash
bun run dev:app:auth
bun run dev:app:chhan-chhan
```

### Run Tests

```bash
cd apps/chhan-chhan && bun test src/lib/importers/
```
