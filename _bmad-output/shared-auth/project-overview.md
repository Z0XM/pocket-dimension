# Project Overview — `@pocket-dimension/auth`

Shared Better Auth configuration for auth-service (HTTP) and auth-backed SvelteKit server hooks.

| Field | Value |
| --- | --- |
| Type | library |
| Public export | `auth` only |
| Deps | better-auth, resend, zod, `@pocket-dimension/db`, `@pocket-dimension/utils` |

## Consumers

| Role | Apps |
| --- | --- |
| HTTP owner | `apps/auth-service` |
| Server hooks | watchlist, zeo, howwasyourday, chhan-chhan, me-via-you |

**Not used by:** pocket, markitdown, dashboard, rhymes, heimdall.
