# Docker Archive

This directory contains archived Docker configuration files from before the migration to Railpack.

These files are kept for reference but are no longer used for deployment. The project now uses Railpack for deployment via Dokploy.

## Archived Files

- `backend-api.Dockerfile` - Original Dockerfile for backend API service
- `web-z0xm.Dockerfile` - Original Dockerfile for web app service
- `docker-compose.yml` - Production Docker Compose configuration
- `docker-compose.dev.yml` - Development Docker Compose configuration
- `DOCKER.md` - Original Docker documentation

## Migration

See `RAILPACK.md` in the project root for current deployment instructions using Railpack.
