# Catalogue · Lacquer Spine Wall

## Scope
Protected Catalogue shell + track list. Mode: Operate.

## Audience / job
Friends & personal multi-device listening — find tracks fast, play/enqueue without friction.

## Direction contract

**THESIS:** Catalogue as a lit spine wall — dark lacquer ground, dense track rows like album spines, play controls sized like a remote; refuses card grids and costume dashboards.

**OWN-WORLD:** Charcoal lacquer field; bone foreground; one electric signal (atmosphere-tinted); circular remote play; now-playing as a single LED edge inset. One grotesque family ranked by size/weight. Off-centre content rail discipline; fixed row rhythm.

**STORY:** Visitor opens Catalogue, scans spines, hits play — queue continuity is obvious via the lit row.

**FIRST VIEWPORT:** Top chrome (Zap + primary nav). Slim filter strip. Main: dense spine track list filling the viewport; Add music as remote-sized primary. Queue dock remains.

**FORM:** Dark Swiss kept as sample default. **Frame** added from locked handoff (coral `#ff6b4a`, Archivo, zero radius, hard rules). Layout notes soft-fit: Catalogue uses Rail-like browse chrome; Frame split stage not forced on browse.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
